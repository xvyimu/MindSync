## 1. 导出默认脱敏

| | |
|--|--|
| **现行** | `exportAllData` 默认 `includeSecrets !== true`；含密钥须二次确认 |
| **若放宽** | 默认含 Key → 误分享/进 git 风险陡增 |
| **可讨论中间态** | 保持默认脱敏；仅优化确认文案/勾选布局（**非**改默认） |
| **决议（本轮）** | **不放宽默认** |

## 2. Web 无 S3 SDK

| | |
|--|--|
| **现行** | UI/Web 无 `@aws-sdk`；S3/R2/WebDAV 仅 Desktop IPC |
| **若放宽** | 浏览器密钥面、包体积、CSP/CORS 复杂化 |
| **可讨论中间态** | 仅 Desktop 增强对象存储 UX |
| **决议（本轮）** | **不放宽**；Web 永不引 S3 客户端 |

## 3. 主安装 auto 默认关

| | |
|--|--|
| **现行** | ADR-005；`enabled` 仅显式 `true` |
| **若放宽「主安装默认开」** | 成本与不可解释性；与工作台定位冲突 |
| **可讨论中间态** | 设置页实验开关（默认关、非主 CTA）— 表单曾允许 |
| **决议（本轮）** | **主路径默认仍关**；实验 UI 可另开 ID，不在本轮 |
