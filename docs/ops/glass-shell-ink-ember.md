# 墨焰 · Ink & Ember（MindSync 专属壳）

> 仅 `?glassShell=1` · 默认 OFF · 不是通用 Fluent/iOS 玻璃拷贝

## 识别符号

| 符号 | 作用 |
|------|------|
| **墨青底** | 深场/浅色「羊皮纸洗墨」底，带纸纹噪声 |
| **焰橙 #f97316** | Paper CTA；选中 chip、主按钮、光轨 |
| **墨蓝 #3b82f6** | 与焰橙组成双色轨（侧栏竖线、弹窗顶线） |
| **侧栏右缘渐变轨** | 产品签名，非系统亚克力默认 |
| **标题渐变字** | 墨→焰，品牌标题 |
| **卡片左焰条** | 工作区卡片身份标记 |

## 故意不做

- 满屏彩虹液态玻璃  
- 黑半透假毛玻璃  
- 换 React / 改业务布局
